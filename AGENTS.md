# Movement Partners website

This is the shared Movement Partners website. Both organization owners may independently request and publish changes.

When either owner requests a website change:

- Fetch the latest `main` branch before editing.
- Preserve existing work from the other owner.
- Implement the change and run appropriate checks.
- Commit and push completed changes directly to `main`.
- Do not require a pull request or the other owner's review.
- Never force-push or discard someone else's changes.
- Resolve conflicting edits while preserving both people's work.

The live website uses this repository's GitHub Pages deployment. Do not create a separate hosted copy.
